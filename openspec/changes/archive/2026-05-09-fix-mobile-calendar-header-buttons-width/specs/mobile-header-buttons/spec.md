## ADDED Requirements

### Requirement: Header buttons do not stretch on mobile
The employee calendar header action buttons SHALL maintain a compact, auto-sized width on mobile viewports instead of stretching to fill the full container width.

#### Scenario: Viewing calendar header on mobile
- **WHEN** the user views the employee calendar on a mobile device
- **THEN** the "Nueva Cita", refresh, and "Tu link" buttons keep an appropriate width
- **AND** they wrap to the next line if they do not fit in one row
