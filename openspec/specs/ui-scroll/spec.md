## Requirements
### Requirement: Calendar day appointments are scrollable on mobile
The calendar component SHALL allow users to scroll through all appointments of a selected day in mobile viewports.

#### Scenario: Multiple appointments on a mobile device
- **WHEN** the user selects a day with multiple appointments on a screen width of 768px or less
- **THEN** the user can scroll vertically to view every appointment in the day panel
